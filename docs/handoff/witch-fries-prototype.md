# 女巫的毒药 / 自由料理台：当前交接说明

更新日期：2026-07-22

公开试玩地址：https://kidcadillac.github.io/threejs_burger/cooking.html

## 当前已完成

- 搭建模式：单指拖动食材，双指缩放；一指不会误转镜头。
- 十个实体料位彼此独立。轻触切换当前材料，长按在对应料位旁打开胶囊选择器。
- 面包位在左侧、四个配料位在上侧、酱料位在右侧；选择控件不覆盖食物。
- 放置支持顶部、底部和中间插层；最终高度由接触解算统一决定，落下时在目标层原位缩放回弹。
- 酱料只允许挤在已经装盘的汉堡层上，不会落到备料区食材。
- 聚焦模式：点击一层选中，拖动只调整这一层的水平位置；拖动空白处旋转视角，双指缩放。
- 聚焦操作胶囊支持上移、下移、旋转、删除，并在层序边界自动禁用无效按钮。
- 最大 60 层；层数增加时镜头自动扩大，保证高层仍可查看。
- 自动存档保存层序、旋转、酱料和每层 X/Z 位置。存档格式为 v2，同时兼容旧 v1 存档。
- 反馈系统保留截图、最近操作回放、层数、库存和设备信息。

## 当前手势

| 场景 | 手势 | 结果 |
| --- | --- | --- |
| 搭建 | 拖动食材 | 放到顶部、底部或指定中间层 |
| 搭建 | 轻触料位 | 切换这一格的材料 |
| 搭建 | 长按料位 | 打开这一格自己的胶囊选择器 |
| 搭建 | 双指捏合 | 放大或缩小工作台 |
| 聚焦 | 点击汉堡层 | 选中这一层并显示半透明包围反馈 |
| 聚焦 | 拖动选中层 | 调整该层 X/Z 位置，Y 仍由接触解算控制 |
| 聚焦 | 拖动空白 | 自由旋转查看汉堡 |
| 聚焦 | 双指捏合 | 放大或缩小汉堡 |
| 聚焦 | 底部胶囊 | 上移、下移、旋转或删除当前层 |
