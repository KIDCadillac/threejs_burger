# 《双头吃货王》创意上下文

> 状态：暂停。2026-07-19 经参考视频核对，用户确认该方向不符合当前要先做的玩法。当前食品主题转入《女巫的毒药：薯条篇》；本文件仅保留早期共享抓取构想，不能作为当前项目需求继续实现。

## 当前状态

- 阶段：主题与核心循环探索。
- 类型：双人、回合制、竞技中带有限合作、轻量聚会游戏。
- 目标平台：优先考虑抖音小游戏。
- 核心卖点：两个玩家共享一个身体或抓取能力，却分别争夺属于自己的食物。

## 已确定方向

1. 玩家分为红、蓝两方。
2. 红方只能有效获取红色目标，蓝方只能有效获取蓝色目标。
3. 食物中可以秘密布置陷阱，形成类似“薯片排雷”的猜测、试探和揭晓情绪。
4. 不能直接复制“9 片薯片、3 个炸弹、先踩中 3 次者输”的完整结构。
5. 陷阱反馈应让角色出糗或改变游戏规则，不鼓励角色互相殴打。
6. 不采用打耳光、踢人、推搡等容易被未成年人模仿的惩罚动作。

## 暂定核心循环

1. 布置阶段：双方秘密放置食物、诱饵或陷阱。
2. 抓取阶段：双方共同控制角色或装置，决定最终抓取目标。
3. 揭晓阶段：食物被吃下后才完全展示是否含有陷阱。
4. 结算阶段：按红蓝归属、公共目标和陷阱效果计算结果。
5. 数个短回合后决定胜负，鼓励立即重赛。

## 安全的陷阱效果候选

- 打嗝导致下一回合瞄准线抖动。
- 舌头打结，只能获取近处食物。
- 脑袋鼓成气球，使身体向一侧倾斜。
- 五官夸张收缩，短暂改变操作反馈。
- 黏性食物把嘴粘住，需要完成简单挣脱操作。
- 红蓝视觉或目标颜色短暂互换。
- 彩色泡泡重新洗牌场上食物位置。

## 主播与传播价值

- 规则需要数秒内看懂。
- 秘密信息让玩家产生试探、怀疑和虚张声势。
- 陷阱揭晓瞬间提供清晰的反应点。
- 夸张但无伤害的角色变形适合录屏和短视频传播。
- 快速重赛有利于连续对局和广告节奏。

## 原创边界

- 可以借鉴隐藏信息、轮流选择、风险逐步升高等抽象设计原则。
- 不复制其他游戏的角色、美术、名称、音乐、界面、固定布局、关卡和完整规则组合。
- 应通过“共享身体控制、红蓝专属食物、公共条件和非伤害型状态变化”形成自己的核心表达。

## 待确认问题

1. 双方具体怎样共同控制同一个身体或抓取能力？
2. 陷阱在放置后何时、以何种程度向对手暴露？
3. 公共失败条件是什么，怎样避免纯粹互相捣乱？
4. 个人胜负主要依据积分、存活、任务完成度，还是其组合？
5. 首个可玩原型需要多少种食物和陷阱？
