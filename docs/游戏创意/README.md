# 双人小游戏本地上下文

本目录将不同游戏创意分开记录，避免玩法、主题和决策互相串线。

## 当前项目

- [女巫的毒药：薯条篇](./女巫的毒药-薯条篇.md)：双人秘密藏毒、轮流选择、风险递增与揭晓反应；当前优先探索。
- [同舟不同心](./同舟不同心.md)：回合制双人划船、秘密出桨、共同生存与个人争分。

## 暂停方向

- [双头吃货王](./双头吃货王.md)：早期共享身体抓取构想；已确认不符合当前食品主题玩法，暂不继续。

## 记录规则

1. 两款游戏分别维护，不默认共享世界观、角色、关卡或数值。
2. 通用的平台上线、版权与未成年人安全结论，可以分别引用，但具体设计决策必须写入对应游戏文件。
3. 尚未获得确认的内容放在“待确认问题”，不能当作已定方案继续开发。
4. 当前均处于创意探索阶段，尚未进入实现。
