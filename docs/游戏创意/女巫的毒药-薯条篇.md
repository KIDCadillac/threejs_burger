# 《女巫的毒药：薯条篇》创意上下文

## 当前状态

- 阶段：参考玩法核对与产品形态探索。
- 类型：双人、回合制、隐藏信息、心理博弈、轻量聚会游戏。
- 目标平台：优先考虑抖音小游戏。
- 当前优先级：先于《同舟不同心》探索。
- 产品形态：完全在屏幕中进行的虚拟双人游戏，不使用真实薯条作为游戏道具。
- 对局入口：同时提供在线快速匹配和邀请好友约战，不在二者之间二选一。

## 已核实的参考玩法

1. 双方各自在同一组食物中秘密指定一份作为自己的“毒药”，不能让对手知道。
2. 双方轮流选择一份食物。
3. 玩家若选中对方秘密指定的“毒药”，立即中毒并落败，对方获胜。
4. 食物不断减少后，安全范围越来越小，猜测、表情误导和揭晓反应构成主要节目效果。
5. 网络上存在水果、炸串、薯条、盲盒及带惩罚的桌游扩展等变体；这些是同一基础机制的不同包装，并非本项目已经确定的规则。

## 方向纠正

- 本项目的核心不是“双人共同操纵一个角色抓取食物”。
- 本项目的核心不是按颜色争抢各自食物。
- 女巫题材目前只作为名称与气氛参考，不应把玩法改成魔法厨房、角色抓取或动作闯关。
- 正确的核心循环是：秘密藏毒 → 轮流试探 → 选项减少 → 毒药揭晓 → 胜负与安全惩罚结算。
- 参考视频中的角色能力、道具牌、食物牌和惩罚层只能用于分析扩展空间，不能直接复制其名称、卡面、数值或完整规则组合。

## 节目效果来源

- 玩家知道自己的毒药位置，却不知道对方的毒药位置。
- 每次选食物前都能观察对方的表情、停顿和语言误导。
- 剩余食物越少，风险越集中。
- 选中瞬间立刻揭晓，形成清晰的惊吓、庆幸或反转节点。
- 单局短、规则简单，适合连续重赛和直播互动。

## 原创特色：赛前调制整蛊薯条

每回合开始时，双方不是只点击一根“毒药薯条”，而是秘密制作一根属于自己的整蛊薯条：

1. 从公共薯条盘中秘密选择一根作为目标。
2. 在两个调味槽中加入辣椒酱、芥末、酸味汁、黏酱等虚拟调味料。
3. 确认后封装配方；对手只能看见普通薯条外观，不能看见位置和酱料。
4. 对局中若对手吃到这根薯条，镜头拉近对手的游戏角色，播放与配方对应的夸张表情和动作，再揭晓制作者与配方。

### 表情组合示例

- 辣椒酱：脸迅速变红、冒汗、喷出卡通火苗。
- 芥末：鼻子一酸、眼泪喷涌、头发竖起。
- 酸味汁：五官收紧、脸颊凹陷、身体短暂抖动。
- 黏酱：嘴被黏住，只能发出含糊声音和挣脱动作。
- 辣椒酱 + 芥末：先强忍镇定，再突然红脸流泪，形成二段反应。
- 酸味汁 + 黏酱：五官缩紧后嘴巴拉长，形成组合表情。

### 平衡原则

- 基础模式中，所有配方命中后都只决定该回合胜负，不改变命中概率。
- 调味料主要改变揭晓演出、表情、音效和收藏记录，避免付费调味料形成战力优势。
- 首版只做少量辨识度很高的调味料和组合，不做复杂烹饪数值。
- 所有反应均发生在虚拟角色身上，不鼓励玩家在线下模仿极辣、芥末或混合刺激物挑战。

### 长线价值

- 玩家可收集新酱料瓶、瓶身皮肤、装盘方式和表情演出。
- 结算页记录“本局配方”，方便截图、录屏和分享。
- 稀有内容以视觉演出和个性化为主，可作为广告奖励或装扮商业化内容。

## 联机与邀请方向

### 首页入口

1. `快速匹配`：进入真人匹配队列，成功后直接进入双方准备阶段。
2. `邀请好友`：立即创建双人房间并调用抖音好友邀请面板；好友点击私信卡片后直接进入该房间。
3. `输入房间码`：作为链接、私信卡片或拉起参数失效时的低优先级兜底入口。

### 参考产品中可学习的部分

- 学习《狙击外星人》把随机对战和好友房间放在同一个双人玩法入口下的结构。
- 学习“创建房间 → 邀请约战 → 好友点击分享或输入房间号加入”的短链路。
- 不复制它的按钮造型、页面布局、名称、角色、美术或射击玩法。

### 抖音平台能力与自有服务分工

- 抖音平台：用户登录、好友邀请面板、私信游戏卡片、分享拉起参数和后续录屏分享。
- 游戏服务端：真人匹配队列、房间创建与回收、回合状态、毒药位置、掉线重连和胜负判定。
- 对局通过安全 WebSocket 连接实时同步；隐藏信息只由服务端向有权看到的一方下发。
- 好友邀请卡片携带房间标识；若使用动态组队卡片，房间开始或失效后同步更新卡片状态。

### 默认体验决策

- 快速匹配默认匹配真人，不把机器人伪装成真人。
- 冷启动人数不足时，明确提供“继续等待”或“与练习对手开局”，不暗中替换。
- 好友进入后省略复杂房主设置，双方加载完成即开始藏毒。
- 房间码采用短数字码并设置有效期，避免永久占用和误入旧房间。

## 安全边界

- 小游戏内的惩罚优先采用夸张表情、临时状态、积分变化或无伤害互动。
- 不把打耳光、推搡、踢人、强迫进食、极辣食物或饮酒设计成推荐玩法。
- 若保留线下食物辅助模式，需要提示过敏、噎食、辛辣刺激和未成年人风险。

## 尚未确认

2. 首版是否采用纯粹的一人一毒药，还是加入轻量角色/道具系统。
3. 惩罚在游戏内采用怎样的夸张但无伤害的表现。
