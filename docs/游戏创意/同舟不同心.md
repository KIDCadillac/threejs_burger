# 《同舟不同心》创意上下文

## 当前状态

- 阶段：主题与核心循环探索。
- 类型：双人、回合制、半合作竞技、轻量聚会游戏。
- 目标平台：优先考虑抖音小游戏。
- 核心卖点：两名对手共乘一条船，必须合作到达终点，但只有个人积分更高者获胜。

## 与现有划船游戏的区别

常见双人划船游戏采用实时操作：一人控制左桨、一人控制右桨，通过同步节奏躲避障碍。本项目不以实时高难度协调为核心，而采用秘密选择、同时揭晓和回合结算，突出预测与心理战。

## 已确定方向

1. 玩家分为红、蓝两方，共乘一条船。
2. 红方控制一侧船桨，蓝方控制另一侧船桨。
3. 每回合双方秘密选择本侧船桨力度，再同时揭晓。
4. 两侧力度共同决定船的前进与偏转方向。
5. 红色目标只给红方个人分，蓝色目标只给蓝方个人分。
6. 金色或中立补给服务于共同航程、船体耐久或生存条件。
7. 双方若忽略共同补给，可能一起沉船；成功抵达后再比较个人分数。

## 暂定回合流程

1. 观察：展示前方河道、障碍、红蓝目标和公共补给。
2. 决策：双方分别秘密选择船桨力度或特殊动作。
3. 揭晓：同时公开选择，计算合力方向。
4. 航行：用简短物理动画表现船的移动与碰撞。
5. 结算：获得个人目标、公共补给或触发陷阱。
6. 河道推进，进入下一回合。

## 初步移动规则

- 两侧力度相等：船直行。
- 左桨更强：船向右偏转。
- 右桨更强：船向左偏转。
- 双方都不划：船受水流或当前环境影响。
- 规则必须让玩家能够推算结果，不能退化成纯随机猜拳。

## 食物与陷阱融合

- 河面目标可以包装成红蓝食物、漂流物或补给箱。
- 玩家可以在赛前或特定回合秘密布置陷阱食物。
- 陷阱不攻击角色，可造成船体旋转、船桨黏住、控制力度受限、红蓝目标短暂互换或河道物品洗牌。
- 应限制恶意沉船能力，避免陌生人匹配中一方从开局就能破坏整局。

## 主播与传播价值

- 秘密选桨后的同时揭晓提供稳定的反应点。
- “你到底想救船还是抢自己的东西”容易产生争吵和笑点。
- 一次选择即可完成一个回合，观看门槛低。
- 预计适合做成短局并支持快速重赛。
- 无需语音即可通过出桨、路线和表情进行博弈。

## 原创边界

- 不复制现有实时划船游戏的关卡、障碍、美术、物理参数和控制表现。
- 核心差异应落在“回合制秘密出桨、红蓝专属收益、共同生存条件、食物陷阱”这一组合。
- 暂定名《同舟不同心》仅作内部代号，后续需进行名称检索并与软著名称规划一致。

## 待确认问题

1. 一局结束时的准确胜负判定是什么？
2. 每侧船桨提供多少档力度，是否包含保留或特殊动作？
3. 河道采用固定关卡、随机生成，还是二者结合？
4. 如何限制故意沉船，同时保留背叛和抢分的乐趣？
5. 首个原型需要多少回合、目标类型和陷阱类型？
