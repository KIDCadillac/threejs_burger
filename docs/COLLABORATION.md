# 汉堡小游戏：双电脑协作约定

## 共用仓库

- GitHub：`https://github.com/KIDCadillac/threejs_burger.git`
- 试玩：`https://kidcadillac.github.io/threejs_burger/`
- `main` 只用于已经验收、可以公开试玩的版本，两台电脑都不要直接在 `main` 上开发。

## 分工分支

- 台式机：`codex/desktop-gameplay`
  - 负责交互、玩法、状态、测试、部署。
- 笔记本：`codex/laptop-art`
  - 负责餐车/寿司吧台美术、灯牌、菜单灯箱、人物与开关门动画。

两边都可以查看另一边的分支，但只提交到自己的分支。需要合并时，先在本文件记录改动和验证结果，再由台式机合并到试玩版。

## 当前基线（2026-07-26）

台式机已完成：

- 汉堡餐车与寿司吧台主页卡片、循环滑动和开关门过渡。
- 营业牌、地图说明随卡片联动。
- 自由练习、复刻对决、双人模式切换；图鉴保留在底部入口。

## 合并规则

- 不提交缓存、日志、录屏、临时截图和 Base64 文件。
- 美术资源放入独立资源目录，不覆盖同名现有文件。
- 一次提交只处理一个主题，提交说明写清楚用途。
- 合并前先同步远端，再运行现有测试。
- 只有台式机验收通过后，才更新 `main` 和公开试玩链接。
