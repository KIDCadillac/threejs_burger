## 本轮结果

### 主页最基础横向动画

- 根因不是轮播状态机缺失，而是 `home-layout-editor.mjs` 在普通主页启动后清空了店铺卡片的内联 `transform`，导致五张缓冲卡片全部叠在中间，看起来像无动画换截图。
- `home-lobby-app.mjs` 现在通过独立的 `--map-carousel-transform` 保存整排店铺位姿；布局编辑器继续使用自己的拖动、缩放、旋转和透视通道，两者不再互相覆盖。
- 主页始终保留 `-2 / -1 / 0 / 1 / 2` 五个缓冲位置。相邻店铺在左右两侧排队，切换时完整卡片连同餐车、车轮、招牌、窗口和人物一起运动。
- 前进和返回使用镜像位置；卡片循环回收后仍恢复原顺序，不会出现滑出去有动画、滑回来瞬移。
- 原有完整银色餐车进场、车轮滚动、卷帘打开和返回汉堡页自动重播继续保留；本次只修正承载它们的主页基础轨道。

- 自动化测试更新为 29 项并全部通过；真实浏览器使用实际指针手势完成“寿司 → 汉堡 → 寿司”双向滑动，左右卡片位姿为 `-176% / -88% / 0 / 88% / 176%`，前进和返回后活动卡片均正确回到 `0`，控制台错误为 0。

## 台式机接手

先在台式机仓库检查是否有未提交内容：

```powershell
git status --short --branch
```

确认不会覆盖台式机本地工作后：

```powershell
git fetch origin
git switch main
git pull --ff-only origin main
```

台式机先以 `main` 为准继续开发。不要在有未提交修改的工作区强行切分支。

如果笔记本已经在编辑器里调整过参数，还要从顶部“下载调整文件”，把 JSON 发给 Codex 固化代码，或在台式机的 `?layout=1` 页面点“导入调整文件”。Git 只同步代码，不同步浏览器 `localStorage`。

本次 2026-07-29 的前后轮调整已经固化进 `main`，台式机拉取本次提交后不需要重复导入。若台式机浏览器以前保存过另一组本地参数，它会继续优先显示本地结果；在编辑器点“全部复位”即可切回仓库基准。

网格、边距和自动吸附偏好保存在 `burger.home.editor-guides.v2`；这些同样只存在当前浏览器。跨电脑时最重要的 UI 结果仍以“下载调整文件”导出的 JSON 为准。

## 禁止回退

- 不要再用黄色车头和奶油车厢拼车。
- 不要再让近景只剩两只手；人物必须在中心。
- 不要把一张整车截图直接缩放当完整动画。
- 不要让大轮胎、黑色圆形或按钮遮挡出餐口。
- 不要使用摄影金属反射、霓虹塑料高光或软陶 3D 风格。
- 不要在没有同屏对比和浏览器交互回归时写 `passed`。
