# 主页三卡轮播与店铺封面重构设计

## 目标

把主页从“网页功能列表”重构成一眼能懂的游戏大厅，并彻底解决循环滑动时反弹、邻卡消失和图层延迟的问题。主页只承担三件事：选择店铺地图、选择当前玩法、开门或关门。

## 交互结构

### 地图轮播

- 使用固定的“上一张、当前张、下一张”三卡窗口，不再让真实卡片在首尾克隆之间跳转。
- 当前卡保持正面；左右邻卡分别旋转约 `45°` 和 `-45°`，缩小但保持清晰，露出足够封面内容。
- 拖动时三张卡同步跟手；越过阈值后完成切换，否则回到原位。
- 动画结束后只更新三张卡承载的地图数据，再无动画地复位位置，因此可以无限循环且不会空层、闪烁或反弹。
- 左右按钮、键盘和触摸滑动共用同一个切换状态机。

### 玩法切换

- 保留地图区域内的上下滑动切换玩法。
- 删除地图下方的“自由练习、汉堡图鉴、复刻对决、寿司店”四按钮网格。
- 当前玩法只显示为一块紧凑挂牌；切换时使用上下翻牌动画。
- 点击当前地图进入所选玩法；尚未开放的组合只给出明确提示。

### 营业按钮

- 页面主操作只保留一个实体挂牌式“开门营业 / 关门打烊”按钮。
- 店铺未开放时，主按钮改为不可操作的“筹备中”，不会误导玩家。

## 视觉结构

- 地图封面成为主页视觉中心，整体尺寸大于现有卡片。
- 汉堡店使用白天暖色后厨窗口、招牌汉堡和厨师动作，强调正在营业。
- 寿司店使用夜间蓝绿色店面、红灯笼、寿司吧台和完整师傅形象；“新店预告”改为封面内部角标，不再单独占据上方空间。
- 左右邻卡保留可辨识的店铺标题与主体，不只显示一条边。
- 删除四按钮后释放的空间用于放大封面和营业挂牌，底部仅保留主导航。

## 组件与状态

- `home-map-carousel-state.mjs` 提供纯状态函数：循环索引、三卡内容映射、拖动姿态和切换结果。
- `home-lobby-app.mjs` 负责手势生命周期、动画阶段和三张卡的数据刷新。
- HTML 提供三个稳定卡槽；每个卡槽包含可替换的店铺封面容器。
- CSS 使用统一的位移、旋转、缩放和透明度变量呈现三卡姿态，不再依赖首尾克隆。
- 地图索引和玩法索引继续保存到本地存储；旧存档索引仍然有效。

## 异常处理

- 动画进行中忽略重复指针提交，但继续安全处理取消事件。
- 指针取消、窗口尺寸变化或手势未达到阈值时，三卡统一回到稳定位置。
- 地图数量为一张时自动隐藏邻卡和切换控件。
- 不可用地图不会进入空白页面。

## 验收与测试

- 连续向左或向右滑动至少十次，顺序循环且无反弹、空白邻卡或延迟刷新。
- 每个静止状态都能同时看到当前卡及左右约 `45°` 的邻卡内容。
- 上下滑可循环切换玩法，删除的四按钮不再出现在 DOM。
- 寿司店封面占满主卡，并在封面内部显示“新店预告”。
- 手机窄屏、桌面宽屏、触摸取消和窗口缩放均保持可操作。
- 为三卡映射、循环切换、拖动姿态和页面结构增加自动化回归测试，再运行现有全部 Node 与 Python 测试。
