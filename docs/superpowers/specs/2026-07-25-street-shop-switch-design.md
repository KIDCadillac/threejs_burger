# 街区换店动效设计

## 目标

主页切换不再像翻一张通用卡片，而像沿街快速换店：

- 汉堡页是一辆餐车：离场时窗口卷帘落下、车轮启动，整辆餐车横向驶走。
- 寿司页是一座吧台：离场时暖帘落下、吧台横向退场；入场后暖帘打开，石板台露出。
- 左右滑动和按钮都必须连续循环、可被下一次手势打断，不允许反弹或长时间锁住。

## 交互

1. 拖动时只移动当前店和相邻店，相邻店较小、略暗，但能辨认店型。
2. 松手达到阈值后，当前店在约 100ms 内关门，下一家店立即被拉入。
3. 主位移动约 270ms；到位后开门动画不阻塞下一次操作。
4. 减少动态模糊和大面积滤镜，使用透明遮罩表达远近，保证手机端稳定。

## 性能策略

- `pointermove` 只记录最新进度，通过 `requestAnimationFrame` 每帧最多渲染一次。
- 每张店卡拖动期间只更新 `transform`、`opacity`、层级和轻量遮罩。
- JS 和 CSS 使用同一过渡时长，避免动画尚未结束就重置缓冲区。
- 只有拖动/切换阶段启用 `will-change`。

## 验收

- 连续向同一方向快速滑动时保持循环，不反弹。
- 汉堡与寿司呈现不同的关门/开门动作。
- 切换总等待明显短于旧版，手势期间无明显掉帧。
- 桌面和手机比例下，相邻店不穿过主卡边缘。
