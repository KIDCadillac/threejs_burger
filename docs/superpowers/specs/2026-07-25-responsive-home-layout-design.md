# 自适应主页布局设计

## 目标

把主页从依赖固定 `top` 与固定最小高度的网页布局，改成能适应不同手机宽高、刘海安全区和桌面预览的游戏大厅布局。

## 结构

主页主体采用四段纵向布局：顶部资源栏、木牌与店名、地图轮盘、底部导航。地图轮盘占用剩余可用高度，并通过最小/最大值限制避免超宽桌面或矮屏手机失真。矮屏只压缩间距和装饰，不把地图硬性缩成不可操作的小卡片。

## 交互

- 木牌、绳子和牌面作为一个整体执行翻牌动画。
- 当前玩法标签位于中央地图卡片内部，并跟随卡片拖动、旋转和切换。
- 左右邻居卡片沿与当前位置相反的方向旋转约 45 度，以展示朝向中央的内侧内容。
- 删除独立页码；地图循环关系通过可见的两侧卡片表达。

## 响应式规则

- 使用 `100dvh`、安全区变量和 CSS Grid 分配垂直空间。
- 地图高度使用 `clamp()`，同时受可用视口高度约束。
- 窄屏缩小横向边距和箭头，不压缩主要内容文字到不可读。
- 矮屏缩小 HUD、木牌与标题间距；底栏保持至少 56px 触控高度。
- 桌面维持手机比例的最大宽度，避免内容横向拉伸。

## 验收

自动化测试必须验证结构不再使用 `top: 8.1rem`，玩法标签位于地图视口内、页码被移除、木牌整体动画生效、左右卡片角度方向正确，并保留地图循环切换逻辑。
