# 主页与汉堡料理台第二轮升级设计

日期：2026-07-20

## 背景与目标

当前公开地址会直接进入“自由料理台”，缺少完整游戏入口；汉堡场景虽已支持自由叠放、插层与实时挤酱，但仍存在主页缺失、加载等待感过强、镜头俯仰范围偏小、酱料像管子且可能穿模、汉堡低多边形感明显、缺少成品聚焦查看等问题。

本轮要交付一个能被玩家理解的产品外壳，以及一版更接近“卡通偏真实”的汉堡料理体验。寿司作为下一张地图明确出现在主页，但本轮不做半成品寿司操作台。

## 参考边界

用户提供的老爹系列店铺截图用于参考“多料理地图入口一目了然”的信息结构；《潜水员戴夫》和烹饪模拟器截图用于参考暖色料理台、可操作食材及成品展示感。

只借鉴交互原则和信息层级，不复制第三方角色、图标、名称、素材或具体版式。

## 方案比较

### 方案 A：只补几个按钮和参数

直接在现有料理页增加返回、聚焦按钮，调大镜头范围并加高酱料。改动快，但公开地址仍不像完整游戏，后续加寿司时还要重做入口与页面结构。

### 方案 B：主页壳层 + 独立料理场景升级（采用）

把根页面改为料理地图主页，汉堡页保持独立；主页明确展示“汉堡可玩、寿司下一张地图”。同时在汉堡场景中独立处理加载、镜头、聚焦、酱料几何和模型细节。此方案能立即改善玩家第一印象，也为后续地图保留清晰入口，风险和工作量适中。

### 方案 C：现在就搭完整多地图料理引擎

抽象所有食材、工具、工序、订单与场景配置，再同时做汉堡和寿司。长期扩展性最好，但会把本轮大部分时间耗在抽象层，玩家看到的实际改善反而更慢。

## 页面与导航设计

### 新主页

公开根地址进入“开饭啦”料理地图主页，而不是直接进入 3D 场景。页面采用暖色餐厅招牌感，但保持原创视觉。

主页包含：

- 品牌区：简短说明“自由做菜，也能和朋友互坑”。
- 主地图区：大卡片展示料理类型和状态。
- “自由汉堡店”：状态为“可玩”，点击进入 `cooking.html`。
- “深夜寿司店”：状态为“下一张地图”，展示即将开放，不误导为可玩。
- 玩法预告：自由料理为当前主模式；双人毒药玩法作为后续模式说明，不抢占当前主入口。

料理页左上角提供明确的返回主页入口。

### 加载反馈

保留加载阶段说明、进度条、百分比和慢网提示，移除可见的“已等待 X 秒”。内部仍可计时，以便超过阈值时显示普通的慢网说明，但不把秒数不断呈现给玩家。

## 镜头与聚焦模式

### 自由镜头

水平继续支持完整环绕。垂直俯仰扩大到接近桌面低视角与接近俯视的范围，目标区间约为 1°–89°，同时保持距离限制，避免镜头穿进桌面。

### 聚焦汉堡

料理页增加单个“聚焦汉堡”按钮：

- 开启后隐藏料理台、盘子、料盒、酱料瓶和其他工具，只保留当前汉堡及中性背景。
- 镜头平滑靠近汉堡，玩家仍可拖动查看成品。
- 再次点击“返回料理台”，恢复所有场景物体和之前的工作台镜头。
- 切换时清理临时拖拽、选中轮廓和落点提示，避免残影。

聚焦只改变展示状态，不改动汉堡层级、酱料数据和撤销历史。

## 酱料几何升级

### 问题根因

当前酱料使用圆管沿食材表面路径生成。圆管截面会向表面内侧扩展，遇到弧形面、斜面或边缘时会产生穿模；较少的径向分段又让酱料看起来像多边形塑料圈。

### 新实现

把酱料改为贴合表面的“半圆挤酱带”：

- 每个路径采样点同时取得食材表面位置和局部法线。
- 截面底部贴在表面上方的安全间隙，所有可见顶点只向法线外侧鼓起。
- 横向宽于纵向厚度，模拟挤压后略扁的真实酱线。
- 增加截面和平滑路径分段，材质提高光泽、降低粗糙度。
- 实时预览与放手后的正式酱料继续共用同一份几何生成逻辑，保证所见即所得。
- 酱料仍参与咬痕变形，但不参与食材点击命中。

测试会验证酱料最低点不低于其投影表面，并验证实时预览与最终酱料使用一致几何。

## 汉堡模型细节升级

整体仍采用轻量的风格化 3D，以保证手机浏览器性能，但不再依赖明显的硬面低多边形效果：

- 面包、肉饼、番茄、酸黄瓜和生菜提高圆周分段并使用平滑着色。
- 面包增加烘烤边缘、更多芝麻与轻微不规则轮廓。
- 肉饼增加深浅变化和少量烤纹。
- 番茄增加果肉/籽区细节，酸黄瓜增加籽和沟槽，生菜增加叶脉与边缘变化。
- 奶酪保留自然下垂轮廓，但修正过硬的角和过薄的视觉。
- 新增细节对象统一禁止射线命中，避免破坏拖拽交互。

所有改动受移动端三角形预算约束；通过复用几何、实例化与小型装饰实现细节，不引入大纹理或外部模型加载。

## 状态与兼容性

- 主页使用语义化静态 HTML 和 CSS，避免入口页再产生额外 JavaScript 加载等待。
- 料理状态、层级插入、撤销、酱料提交等现有数据结构不变。
- 聚焦模式属于视图状态，不写入料理存档。
- 保持鼠标、单指拖拽、双指缩放和桌面键盘辅助操作。
- GitHub Pages 继续使用同一个公开链接，更新后链接不变。

## 验收标准

1. 公开根地址显示原创料理主页，汉堡卡可进入料理页，寿司清楚标注下一张地图。
2. 加载层不再显示累计秒数，仍有阶段、进度和慢网提示。
3. 镜头可接近水平低视角和正上方俯视，水平仍可完整环绕。
4. 一键聚焦时画面只保留汉堡，返回后工作台完整恢复，料理数据不变。
5. 预览酱料与放手后的酱料实时一致，线条更圆润，无明显穿入食材。
6. 汉堡边缘更平滑并有可见食材细节，移动端帧预算测试不过度回退。
7. JavaScript、Python 和浏览器回归测试全部通过；在 390×844 手机视口完成主页、进入料理、聚焦与返回流程验收。
