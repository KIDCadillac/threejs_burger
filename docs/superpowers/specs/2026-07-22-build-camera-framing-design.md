# 搭建模式宽视野镜头设计

## 背景与问题

当前搭建模式会在恢复存档、窗口尺寸变化和部分堆叠操作后，使用汉堡堆本身的包围盒重新取景。短汉堡的包围盒很小，因此镜头会被拉到汉堡附近，造成餐盘、配料台和两侧材料区域被裁切。这个行为与“搭建时固定视角、聚焦时自由观察”的交互目标冲突。

## 目标

- 搭建模式优先展示完整工作台，而不是让汉堡占满画面。
- 普通层数的汉堡不能让搭建镜头自动拉近。
- 搭建模式锁定观察角度和目标点，但允许玩家用双指主动放大、缩小。
- 汉堡持续增高时，镜头可以自动后退和上移，确保最高层仍然可见。
- 聚焦模式继续按汉堡本体近距离取景，并允许自由旋转和缩放。
- 从聚焦模式返回后，恢复进入聚焦前的宽视野；若堆叠高度已变化，再向外扩展到安全距离。
- 手机竖屏、手机横屏和桌面窗口都遵守同一套取景规则。

## 方案

### 1. 分离两种取景策略

搭建模式与聚焦模式不再共用“只适配汉堡包围盒”的距离计算：

- **搭建模式**：以完整工作台安全取景作为自动基线。自动适配只能保持或增大该距离，不能主动比基线更近；玩家双指缩放属于明确手势，可以在受控范围内主动靠近或远离。
- **聚焦模式**：继续只使用汉堡堆包围盒计算紧凑距离，以便近距离检查和删除分层。

### 2. 搭建模式的宽视野基线

创建料理场景时，以工作台实体包围盒和当前相机宽高比计算搭建镜头基线，包括目标点、朝向和距离。基线使用与堆叠适配相同的安全边距，因此不依赖固定像素或某一种手机尺寸。任何恢复存档、窗口尺寸变化、镜头复位或退出聚焦触发的重新取景，都必须至少满足当前宽高比下的这份基线。

短汉堡使用基线目标点和距离，完整显示餐盘、后方四个配料位、左侧面包区和右侧酱料区。汉堡超过基线可容纳高度后，沿用现有堆叠包围盒算法增加目标高度与距离。

### 3. 搭建模式双指缩放

- 单指拖动画布仍不旋转、不平移镜头，搭建角度和目标点保持固定。
- 两根手指都从画布空白区域开始时，用指间距离控制相机距离；手指拉开时放大，捏合时缩小，方向与手机相册一致。
- 双指缩放只改变距离，不改变方位角、俯仰角和目标点。缩放范围由“不会穿过工作台或汉堡”的最近距离与 60 层取景仍可用的最远距离共同限制。
- 自动恢复存档、删除层、短汉堡重新取景和普通窗口变化不得抹掉玩家刚刚选择的距离；只有当前距离已经不足以容纳新高度或新宽高比时，系统才平滑后退到新的安全下限。
- “镜头复位”恢复当前视口下完整工作台的安全基线，不恢复到汉堡近景。

### 4. 模式切换

- 进入聚焦：保存当前搭建镜头，隐藏工作台，按汉堡包围盒紧凑取景，开放轨道旋转与缩放。
- 退出聚焦：恢复保存的搭建镜头；如果删除或改变分层后仍需要更大视野，只允许继续后退，不允许自动靠近。
- 搭建模式中拖动空白区域仍不会旋转镜头。
- 搭建模式双指缩放与聚焦模式轨道缩放共用相同的手势方向，但搭建模式永远不响应单指旋转。

## 边界与异常处理

- 空餐盘没有汉堡包围盒时，直接使用工作台基线。
- 只要汉堡包围盒仍可被工作台基线容纳，汉堡层数就不能改变搭建镜头为近景。
- 最高 60 层仍使用现有动态扩展逻辑，并继续扩展远裁剪面，避免顶部被裁掉。
- 视口方向改变时重新计算当前宽高比下的安全搭建距离，但不能退化成只看汉堡。
- 玩家主动放大后继续叠高时，如果最高层即将离开安全区，镜头只后退到刚好容纳新堆叠的距离；不额外跳回默认远景。
- 不改动食材尺寸、摆放坐标、聚焦删除逻辑和侧边材料按钮布局。

## 验收标准

1. 390×844 手机竖屏下，搭建七层汉堡时能同时看到完整餐盘、后方配料位以及左右材料区域。
2. 从空餐盘叠到七层，搭建镜头不会逐层靠近。
3. 恢复七层存档和旋转手机后，镜头仍保持宽视野。
4. 进入聚焦后汉堡可以占据主要画面，并可自由旋转、缩放、选择和删除层。
5. 返回搭建后恢复宽视野；删除中间层不会让镜头突然靠近。
6. 60 层汉堡仍完整位于画面安全区域内。
7. 搭建模式中双指拉开会连续放大、捏合会连续缩小；单指拖动不会改变镜头角度。
8. 玩家放大后添加仍可容纳的层不会突然重置镜头；超过安全高度时镜头只平滑后退到必要距离。
9. 点击镜头复位后恢复完整工作台基线，退出聚焦后恢复进入聚焦前的搭建缩放距离。

## 测试策略

- 单元测试覆盖搭建基线距离、恢复存档、视口变化、聚焦往返、60 层动态扩展、搭建模式双指缩放方向和缩放边界。
- 交互测试明确断言搭建模式单指拖动不旋转、两指缩放只改变距离，并验证新层触发的安全后退不会改变方位角和俯仰角。
- 先新增一个能复现“七层汉堡把镜头拉近”的失败测试，再修改生产代码。
- 使用 390×844 真实浏览器尺寸完成空餐盘、七层搭建、聚焦和返回搭建的截图对比。
- 最后运行完整 Node 与 Python 测试，并检查浏览器控制台无错误。
