# 汉堡分层插入与半透明预览设计

## 目标

修正食材插入时从汉堡底部穿过整叠食材的问题，并让玩家在松手前后都能看懂“这块食材会放在哪一层”。

## 已确认交互

1. 抓起食材后，食材本体外侧出现一层贴合其真实几何外形的半透明包围壳；它随食材移动、旋转和缩放，不参与射线选取。
2. 食材进入餐盘有效吸附区域后，目标插层处显示同一种食材的半透明 3D 预览。预览采用最终落点、最终角度和最终尺寸，让玩家松手前直接看到组合结果。
3. 原有目标圆圈退居辅助地位：它可以保留为很弱的地面定位光环，但食材形状预览必须成为主要反馈。
4. 松手后，预览立即隐藏，真实食材直接出现在目标插层。食材不再从拖动位置或汉堡底部穿行，而是在目标高度由小到大弹出：缩小 → 略微放大过冲 → 回弹至正常尺寸。
5. 目标层以下的食材保持不动；目标层以上的食材只移动到为新层让出的最终高度。无论插在底部、中间还是顶部，新食材都遵守同一套“目标层原位缩放”规则。
6. 动画结束时，每层恢复权威堆叠坐标与统一展示比例；预备区食材不得因插入动画而移动。
7. 开启减少动态效果时，直接显示最终结果，不执行缩放弹出，但仍保留拖动时的包围壳和落点预览。

## 视觉参数

- 抓取包围壳：复用食材自身几何，外扩约 5%，暖金色半透明填充，边缘可见但不遮住食材纹理。
- 落点预览：复用目标食材几何，约 24%–32% 不透明度，深度写入关闭，保持正常深度遮挡。
- 原位弹出：约 0.64 倍开始，峰值约 1.08 倍，随后回落到 0.97 倍并稳定为 1 倍；纵向位移只允许很小的正向弹性，不得低于最终目标高度。
- 上层让位：只移动 `targetIndex` 以上的已组装食材；下层与预备区保持原位。

## 验收标准

- 底层插入过程中，新食材的 Y 坐标从不低于最终插层 Y 坐标。
- 中层、顶层插入同样从目标层原位缩放，不穿过任何已有食材。
- 拖动有效落点时能看到目标食材的半透明形状，而不是只看到一个圆圈。
- 抓取反馈几何与当前食材一致，切换食材时不会继续显示上一块食材的外形。
- 取消、无效落点、页面隐藏、聚焦模式和销毁场景时，所有临时包围壳与预览均会清除。
- 全部 Node 与 Python 自动化测试通过，并在手机尺寸浏览器中完成拖放视觉验收。
