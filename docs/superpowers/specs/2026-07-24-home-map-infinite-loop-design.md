# 主页地图无限循环设计

## 目标

主页地图沿一个循环序列滑动：汉堡店 → 寿司店 → 汉堡店；反向同样循环，首尾不出现停顿或禁用状态。

## 交互设计

- 保留浏览器原生横向滚动、惯性和 `scroll-snap`，不在手指移动时重绘。
- 物理轨道为“末页复制、真实页面、首页复制”。滑到复制页并停止后，无动画跳回视觉完全相同的真实页。
- 左右箭头始终可用；圆点、页码、标题和本地存档只反映真实地图。
- 键盘左右键、圆点点击、箭头点击和手势滑动共享同一套逻辑。

## 边界与无障碍

- 复制页标记为 `aria-hidden` 和 `inert`，避免屏幕阅读器和焦点重复。
- 窗口尺寸变化后重新定位当前真实地图。
- 跳回真实页时临时关闭平滑滚动和吸附，下一帧恢复，避免肉眼看到反向回弹。

## 验收

- 从第一张向右、从最后一张向左都能继续滑动。
- 连续多次同方向滑动不会卡在边界。
- 左右箭头不会禁用。
- 刷新后仍停在上次选中的真实地图。
- 现有主页和料理测试全部通过。
