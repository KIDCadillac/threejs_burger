# 汉堡餐车主页视觉改造规格

## 目标

把主页中央的汉堡地图从“通用网页卡片”改成一眼能认出的快餐餐车，同时保留现有地图轮播、卷帘门营业状态、玩法切换和移动端响应式行为。

## 已确认方向

- 主色使用番茄红、芥末黄、深棕黑和暖白，不出现任何真实快餐品牌名称或标志。
- 餐车顶部保留红白遮阳篷，窗口增加暖光入口牌。
- 点餐窗口左右各放一个三面菜单灯箱，轮播汉堡、薯条、饮料与套餐信息。
- 菜单灯箱仅在当前卡片静止时转动；拖动地图、后台卡片和系统“减少动态效果”时暂停。
- 灯箱、入口牌和餐车外壳均使用 CSS/HTML 轻量绘制，不增加图片下载和首屏体积。
- 不改变寿司店结构，不重做地图切换状态机，避免再次引入滑动抖动。

## 交互与性能

- 地图拖动期间不创建或销毁节点，只更新现有 transform。
- 新动画只作用于 transform、opacity 和 filter，禁止在帧循环里触发布局。
- 当前卡片使用 `data-card-offset="0"` 激活菜单轮播，非当前卡片保持静止并降低亮度。
- 入口牌有低频暖光呼吸，不闪烁；灯箱每次停留足够长，儿童也能看清。

## 验收标准

- DOM 中存在餐车标识、入口牌、两个菜单灯箱和每个灯箱三个菜单面。
- 页面不包含真实快餐品牌名称。
- 拖动地图时灯箱停止动画，松手并成为当前卡片后继续。
- 现有主页、营业卷帘门、玩法人数和寿司店测试保持通过。
- 手机窄屏下入口牌、灯箱不遮挡主汉堡和营业卷帘门。
