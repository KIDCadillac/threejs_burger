# 主页地图 3D 卡片转盘设计

## 目标

把主页地图从平面横向滚动改成有空间感的循环卡片转盘。玩家可点击左右箭头、左右拖动或使用键盘方向键切换地图；当前地图正面居中，相邻地图以侧面卡片形式预览。地图转盘与下方四个游戏模式入口互不遮挡、互不联动。

## 交互

- 当前卡片位于中央，缩放为 1，绕 Y 轴旋转为 0。
- 上一张和下一张卡片分别露在左右两侧，带透视、缩小和向内倾斜。
- 拖动时卡片姿态实时跟随手指，不等松手才播放。
- 松手后按距离和速度判定上一张、下一张或回弹；切换后自动吸附居中。
- 点击左右箭头播放同样的转盘动画，并保持无限循环。
- 一次动画只移动一张，动画未结束时合并重复输入，避免快速点击造成跳帧。
- 移除底部圆点和“左右滑动切换地图”文字，仅保留页码。

## 结构

- `home-map-carousel-state.mjs` 只负责索引循环、拖动进度和卡片姿态计算。
- `home-lobby-app.mjs` 负责指针事件、箭头和键盘输入，并把姿态写入每张卡片的 CSS 变量。
- `home.css` 使用 `perspective`、`rotateY`、`translateX`、`scale` 和层级完成 3D 转盘。
- `index.html` 保留语义化地图区域与箭头，删除圆点控件和冗余提示。

## 边界与兼容

- 触摸拖动只接管横向意图，纵向滑动仍允许页面滚动。
- 地图不足两张时隐藏箭头，不启用转盘。
- `prefers-reduced-motion` 下取消翻转过渡，直接完成切换。
- 地图标题、营业状态、主按钮链接和本地存档继续跟随当前地图。

## 验收

- 左右箭头、拖动和键盘都按同一循环顺序切换。
- 中央、左侧、右侧卡片分别呈现正面和倾斜预览。
- 拖动过程连续，松手吸附，不出现空白帧或突然跳回。
- 四个模式入口、开门营业按钮和矮屏滚动布局保持可用。
- 状态单元测试、主页结构测试与全套现有测试通过。
