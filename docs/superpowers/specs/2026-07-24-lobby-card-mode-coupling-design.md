# 首页卡片与玩法联动设计

## 目标

首页的地图卡、当前玩法和营业状态要看起来属于同一家店，而不是三个互不相关的网页区块。

## 已确认交互

- 左右切换地图时，当前玩法牌跟随当前卡片一起移动和翻转。
- 汉堡小馆只循环汉堡玩法；切换到寿司店时自动显示“寿司店 / 筹备中”，切回后恢复汉堡玩法。
- 在当前地图上上下滑动，只循环该地图支持的玩法。
- 营业按钮移动到标题上方，做成可点击的实体挂牌；点击在“开门营业”和“关门打烊”之间切换。
- 寿司店不可营业时，挂牌显示“新店筹备”并禁用。
- 删除“汉堡小馆”标题下面的宣传文案。
- 主卡高度缩短约一成，保留左右两张可读的 45° 侧卡。

## 状态边界

地图状态仍由 `home-map-carousel-state.mjs` 管理；玩法目录和地图允许的玩法关系由 `home-mode-switch-state.mjs` 管理；DOM 更新和手势由 `home-lobby-app.mjs` 负责。布局只在 `index.html` 与 `home.css` 中调整。

## 验收

- 自动测试覆盖地图到玩法的归一化、循环切换和主页结构。
- 旧副标题、底部大营业按钮不再出现在主页。
- 完整 Node 与 Python 测试通过后，部署到原 GitHub Pages 链接。
