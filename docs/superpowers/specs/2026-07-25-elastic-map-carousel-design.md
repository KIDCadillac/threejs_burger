# 地图轮播弹性主卡设计

## 目标

让首页地图轮播具有清晰的主次层级：未选中的左右卡片更小、更低、更靠后；用户拖动时，即将进入中央的卡片随手指连续放大；松手完成切换后，主卡轻微弹起并稳定落位。

## 交互规则

- 中央卡片：缩放 `1`、垂直位移 `0`、深度 `0`，保持完整清晰。
- 相邻卡片：缩放约 `0.78`、向下移动、向后退，并保持朝中央旋转 `45deg`。
- 更远卡片：继续缩小并淡出，不参与点击。
- 拖动期间：所有姿态由连续偏移量计算，禁用 CSS 自动过渡，保证卡片严格跟手。
- 松手切换：使用带轻微过冲的过渡曲线，使进入中央的卡片先弹起再落到 `scale(1)`。
- 松手取消：沿同一条姿态曲线回到原卡片，不改变地图索引。
- `prefers-reduced-motion`：保留最终主次尺寸，取消明显弹性动画。

## 实现边界

- `home-map-carousel-state.mjs` 只负责把连续偏移转换成卡片姿态。
- `home-lobby-app.mjs` 只负责把姿态写入 CSS 变量。
- `home.css` 负责组合位移、深度、旋转和缩放，并定义落位弹性。
- 不改变地图顺序、循环逻辑、营业牌、模式上下滑动和跳转行为。

## 验收标准

1. `cardWheelPose(0)` 返回完整中央姿态。
2. `cardWheelPose(1)` 的缩放不大于 `0.8`，且包含向下和向后位移。
3. `cardWheelPose(0.5)` 的缩放严格位于中央与侧卡之间，证明拖动时连续放大。
4. CSS 变换包含 `translateY`、`translateZ`、`rotateY`、`scale`。
5. 非拖动状态使用带过冲的动画曲线；拖动状态关闭过渡。
6. 现有地图循环、方向解析和全量测试保持通过。
