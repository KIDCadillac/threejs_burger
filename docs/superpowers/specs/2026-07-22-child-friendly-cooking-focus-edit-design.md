# 儿童友好料理交互与聚焦层编辑设计

日期：2026-07-22

## 目标

让八岁儿童不依赖说明文字也能完成三件事：从独立原料槽选择材料、把材料明确地放进汉堡、进入聚焦模式调整某一层。与此同时，酱料只能挤在已经装入汉堡的食材上，不能落到预备区原料。

本次只优化现有汉堡料理台，不新增地图、烹饪生产线、联网模式或侧边 60 层管理器。

## 已确认的交互方向

采用方案 A：聚焦模式中直接拖动选中层，并在底部显示一个简短的胶囊工具条。

- 搭建模式：镜头旋转锁定，只允许双指缩放；玩家专心拿取和堆叠。
- 聚焦模式：只显示汉堡，可自由环绕和双指缩放；点击一层即可选中并编辑。
- 选中反馈：当前层出现贴合模型轮廓的半透明包围层，不使用遮挡食物的大按钮。
- 位置编辑：单指拖动选中层的水平位置；半透明虚影持续显示预计落点。
- 手势分区：从选中层开始的单指拖动只移动该层；从空白背景开始的单指拖动才环绕镜头；双指始终用于缩放，避免移动层与转镜头互相抢手势。
- 高度规则：玩家不能自由拖动 Y 轴。层的高度始终由堆叠顺序、模型上下边界和接触重叠量计算，避免浮空。
- 胶囊工具：只提供向上一层、向下一层、旋转和删除。胶囊固定在画面底部，不盖住汉堡。

## 原料槽与选择器

料理台仍保留 3 个面包槽、4 个配料槽和 3 个酱料槽，每个槽独立设置当前材料。

现有悬浮圆形按钮会覆盖原料，因此改为贴在料理台外缘的窄把手：

- 轻触某个把手只循环该槽的下一种材料。
- 长按某个把手，在该槽旁边弹出横向胶囊选择器。
- 胶囊使用材料缩略图和短名称；当前材料有明显高亮。
- 松手选中材料后胶囊关闭，原料槽即时替换，并短暂放大回弹。
- 胶囊不得遮挡汉堡中心，也不得把 10 个槽合并成 3 个总开关。
- 键盘与辅助功能仍可用 Enter、空格和方向键操作同一选择器。

## 放置手感

一次放置分成四个连续状态：

1. **拿起**：材料抬高、轮廓发亮，原料槽保留空位提示。
2. **接近**：汉堡中出现半透明落点虚影；插入中间时，上方各层实时让开缝隙。
3. **放下**：松手后材料直接落在目标层，不从汉堡底部穿过。材料先轻微压扁，再小幅回弹并稳定。
4. **失败返回**：落在无效区域时材料沿短弧线弹回原槽；不静默失败，也不突然瞬移。

成功放置可在设备支持时触发一次很短的振动；音效与振动都应尊重静音和减少动态效果设置。

所有最终位置由同一个堆叠求解器计算。面包必须完全接触相邻层；芝士、生菜等薄层允许少量视觉重合。

## 酱料命中规则

酱料射线检测只接收 `assembledOrder` 中当前可见的汉堡层表面。

- 原料槽、预览克隆、已从汉堡移除的层和隐藏层不参与酱料命中。
- 瓶嘴移动期间实时检测当前层，实时生成局部坐标的酱料预览。
- 离开有效汉堡表面时立即结束当前酱料线段，不把线段跨接到预备区。
- 整个手势没有命中有效层时不提交酱料，并让瓶子轻弹回底座。
- 换层、拖层和旋转后，酱料继续跟随其所属层，因为酱料点保存在该层局部坐标中。

## 聚焦层编辑数据流

聚焦编辑状态包含：

- `focused`：是否处于聚焦模式。
- `selectedLayerId`：当前选中层。
- `focusDraftOffset`：拖动期间的水平草稿偏移。
- `focusGhostPose`：用于半透明落点预览的最终吸附姿态。

交互流程：

1. 点击汉堡表面，根据命中表面的 `layerId` 选中层。
2. 选中层进入半透明包围状态，底部胶囊出现。
3. 拖动时只更新 X/Z 草稿位置；Y 由目标堆叠顺序重新计算。
4. 松手时把 X/Z 偏移写入该层的持久姿态，然后运行堆叠求解并播放压缩回弹。
5. “上移/下移”交换该层在 `assembledOrder` 中的相邻位置，再对受影响层播放局部让位动画。
6. “删除”沿用现有聚焦删除流程，删除后重新吸附剩余层并重新适配镜头。

横向移动限制在餐盘/汉堡有效半径内。超出范围时虚影停在边界，避免把材料拖丢。

每层的 X/Z 偏移和旋转角度属于汉堡存档的一部分；刷新页面或重新进入存档后继续保留。拖动中的草稿姿态不写入存档，只有成功松手才提交。

## 模块边界

- `workbench-slot-controls.mjs`：长按判定、槽旁胶囊选择器、键盘操作。
- `workbench-slot-control-layout.mjs`：把手定位到料理台外缘并防止互相重叠。
- `cooking-interaction-controller.mjs`：指针状态机、拿起/接近/松手、酱料有效表面过滤、聚焦拖动输入。
- `cooking-solo-stage.mjs`：权威堆叠顺序、层姿态、落点虚影、聚焦层重排、镜头适配。
- `cooking.css`：儿童可读的把手、胶囊、选中包围层和动画视觉。

这些模块通过事件和显式 API 通信；DOM 控件不直接改动 Three.js 对象，Three.js 控制器也不直接修改配方状态。

## 错误处理

- 未选中层时隐藏聚焦胶囊。
- 只有一层时，上移/下移按钮按实际边界禁用。
- 删除最后一层后自动退出聚焦模式并返回搭建视图。
- 指针取消、窗口失焦或页面隐藏时撤销草稿姿态并恢复权威堆叠。
- 不支持振动或减少动态效果时，交互功能仍完整，只移除非必要反馈。
- 任何无效酱料手势不创建空记录，也不消耗库存。

## 验收标准

- 手机搭建视图中，10 个槽的选择入口都不遮挡原料模型。
- 任一槽长按后，胶囊贴近该槽弹出；选择材料只影响该槽。
- 未装入汉堡的原料绝不会出现酱料痕迹。
- 放置到顶层、中间层和底层时，材料都从目标位置缩放回弹，不从最下方穿模。
- 面包层之间没有可见悬空；薄层允许少量重合。
- 聚焦后可选中任意已装层，并调整水平位置、相邻层顺序、旋转或删除。
- 聚焦拖动时显示落点虚影，松手后层仍与相邻层接触。
- 堆到 60 层时，镜头仍可自动适配整个堆叠；聚焦模式可自由环绕和缩放。
- 八岁儿童只看动作提示和视觉反馈即可完成选料、放置和聚焦编辑。

## 测试策略

- 单元测试：长按阈值、槽独立切换、胶囊定位、聚焦位移边界、层顺序交换、删除边界、酱料表面过滤。
- 状态机测试：拿起、预览、有效放置、无效返回、指针取消、聚焦拖动和酱料连续手势。
- Three.js 几何测试：每次提交后相邻层接触误差在允许范围内；面包不得出现正间隙。
- 回归测试：60 层镜头适配、存档恢复、撤销、酱料随层移动、移动端双指缩放。
- 浏览器验收：390×844 手机视口和桌面视口分别走一遍完整流程，并检查没有控件遮挡食材。
