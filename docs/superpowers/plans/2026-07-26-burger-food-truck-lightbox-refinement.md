# 汉堡餐车与灯箱视觉强化实施计划

**目标：** 在现有首页循环地图卡片中，把汉堡地图升级为原创 2.5D 餐车，并保持手机端顺滑、低资源占用。

**架构：** 复用现有地图轮播、卷帘门和状态机，仅扩展汉堡卡片的语义结构与 CSS。新增元素全部为装饰层，不引入图片资源或新运行时依赖。

**技术栈：** HTML、CSS、现有原生 JavaScript、Node.js 测试。

## 任务 1：先补失败测试

**文件：**
- 修改：`tests/cooking-solo-page.test.mjs`

1. 添加餐车驾驶舱、服务框、轮拱、原创灯箱图形的结构断言。
2. 添加灯箱拖动暂停、未选卡片降亮度和减弱动画的 CSS 断言。
3. 运行单测并确认新增断言失败。

## 任务 2：实现餐车结构

**文件：**
- 修改：`app/static/index.html`
- 修改：`app/static/home.css`

1. 在汉堡地图中增加车顶招牌、服务窗口框、驾驶舱、轮拱和车灯。
2. 把两组菜单灯箱改为图形优先的三面菜单箱。
3. 增加当前卡片发光、侧卡片缩小/降亮度以及小屏适配。
4. 只使用 `transform`/`opacity` 做新增动效，并支持减少动态效果。

## 任务 3：验证与发布

1. 运行目标测试。
2. 运行完整 `node --test tests/*.test.mjs`。
3. 检查工作树只包含本次代码与文档。
4. 提交并推送源分支。
5. 同步公开部署工作树，推送 `burger-public/main`。
6. 通过线上 HTML 标记确认 GitHub Pages 已更新。
