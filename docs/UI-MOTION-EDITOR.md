# 汉堡小馆 UI 与动画编辑器 v6

更新：2026-08-01

## 地址

- 普通首页：`https://kidcadillac.github.io/threejs_burger/`
- 编辑模式：`https://kidcadillac.github.io/threejs_burger/?layout=1`

编辑器用于调整项目 UI、档口构图、图层和动画参数。普通玩家页面不会显示编辑工具。

## 当前编辑对象

首页汉堡场景是“悬吊银色出餐档口”，不是完整餐车。默认“档口专注”只显示：

1. 档口镜头
2. 完整悬吊档口
3. 银色档口边框
4. 出餐区域
5. 菜单灯箱
6. 后厨与人物
7. 卷帘
8. 汉堡档口招牌

车头、车身和前后轮不再属于当前结构。

## 选择、移动和微调

- 点击左侧图层，或直接点击中间预览中的目标。
- 鼠标拖动只修改 X/Y，不会改变图层顺序。
- 方向键：每次移动 `1px`。
- `Shift + 方向键`：每次移动 `10px`。
- 数字小键盘：
  - `4`：左
  - `6`：右
  - `8`：上
  - `2`：下
- 输入框获得焦点时，方向键只控制输入框。需要先点击画布或图层，再使用快捷键。

## 对齐与吸附

“对齐到当前容器”提供：

- 左边 / 水平中 / 右边
- 上边 / 垂直中 / 下边

建议流程：

1. 先选目标元素。
2. 用一键对齐确定大位置。
3. 开启自动吸附和 `1px` 或 `4px` 网格。
4. 用方向键做最后微调。

不要只用鼠标目测像素位置。

## 图层顺序

选中零件后可使用：

- 下一层
- 上一层
- 置底
- 置顶
- 恢复原层

拖动不会自动把元素提到最上层。只有上述按钮或“图层级别”输入会改变遮挡关系。

轮播卡片自身的运行时层级由 `--map-carousel-z` 管理，不会再被编辑器的图层复位清除。

## 样式与透视

右侧检查器提供：

- X / Y
- 宽度 / 高度
- 缩放 / 旋转
- 透视距离
- X/Y 透视角度
- 透视原点
- 图层级别
- 不透明度
- 显示 / 锁定
- 亮度 / 饱和度 / 模糊
- 圆角 / 背景 / 文字色

档口是正面扁平舞台，常规调整应保持透视为 `0`。只有明确制作翻牌或纸片旋转时才使用透视。

## 档口原生进场时间轴

当前 v6 基线：

- 起始 X：`0`，动画内部附加左偏摆幅
- 起始 Y：`-128`
- 总镜头时长：`1440ms`
- 档口下落与停摆：`1080ms`
- 卷帘延迟：`930ms`
- 卷帘时长：`360ms`

摆坠结构：

1. 档口从上方快速下落，并带左偏。
2. 在动画约 `64%` 处向右形成第一次冲摆。
3. 在约 `77%` 处向左回摆。
4. 两次短小余摆后归零。
5. 档口接近停稳时打开卷帘。

两根绳有各自的顶部锚点，并随主体下落伸长。不要重新加入横杆或 V 形长绳。

“预览档口动画”会播放一次当前参数，结束后回到可编辑终态。

## 普通首页的首次播放门控

普通首页不会在 CSS 加载时直接播放档口动画。

首次播放顺序固定为：

1. 首页完成首轮渲染并加载图片。
2. 若当天未签到，先打开每日签到弹窗。
3. 用户关闭弹窗。
4. 弹窗退场完成后，档口才开始下坠。
5. 档口停稳并打开卷帘。

页面切到后台、任意弹窗仍打开、资源尚未加载完成时，都不会偷播首次动画。

编辑模式 `?layout=1` 不运行这段首次播放流程，档口直接进入稳定状态，方便选层、对齐和编辑。

## 下载和交回调整文件

点击“下载调整文件”会生成：

`汉堡小馆-UI调整-日期时间.json`

文件包含：

- `layoutDocument`：布局、样式和档口时间轴
- `theatreState`：高级关键帧
- `summary`：已调整元素列表

将 JSON 上传给 Codex，即可把浏览器中的调整写回代码。“暂存到浏览器”只保存在当前浏览器，不会同步到 GitHub，也不会自动出现在另一台电脑。

- v5 的旧档口时间轴迁移到 v6 双绳摆坠基线。

## Theatre 面板

“高级动画面板”用于复杂 UI 关键帧，不用于日常对齐：

- 对齐、位置、不透明度：使用普通检查器。
- 连续关键帧：使用 Theatre。
- 档口吊降与卷帘：使用档口原生时间轴。

## 常见问题

### 键盘不能移动

确认：

1. 已选中一个图层。
2. 光标不在输入框中。
3. 元素没有锁定。
4. 再点击一次画布或左侧图层，让编辑器获得焦点。

### 换电脑后看不到调整

“暂存到浏览器”只写当前浏览器。请下载 JSON，或让 Codex 把结果写回仓库并推送 GitHub。

### 导入后车轮不见了

这是预期行为。当前首页已经取消车辆结构。

### 页面仍显示旧动画

确认页面代码资源版本为 `20260731-entrygate1`，然后强制刷新。图片素材仍可能显示 `weight2`，因为本轮没有修改图片像素。
