# 汉堡小馆 UI 与动画开发工具

最后更新：2026-07-30

编辑入口：`http://127.0.0.1:4173/?layout=1`

公网入口：`https://kidcadillac.github.io/threejs_burger/?layout=1`

这不是面向玩家的功能，而是给项目所有者和 Codex 调整首页 UI、餐车构图和动画使用的开发工作台。普通首页不显示 Studio、图层树或编辑手柄。

## 采用的成熟工具

### Moveable 0.53.0

- 负责页面元素的拖拽、缩放、旋转、尺寸手柄和吸附参考线。
- 直接操作当前真实 DOM，不把首页重建成另一套编辑器画布。
- 项目：`https://daybrush.com/moveable/`
- 许可证：MIT，副本位于 `vendor/moveable/LICENSE`。

### Theatre.js 0.7.2

- `@theatre/studio` 提供正式的属性面板、关键帧、缓动曲线、时间轴、播放头、撤销和项目状态。
- `@theatre/core` 把 Studio 数值实时写回游戏中的 DOM；已保存的 Theatre 时间轴也能在普通页面用 core-only 版本播放。
- 项目：`https://www.theatrejs.com/`
- Studio 仅在 `?layout=1` 开发入口加载；普通页面不会加载 Studio。
- `@theatre/studio` 为 AGPL-3.0，`@theatre/core` 为 Apache-2.0；许可证副本位于 `vendor/theatre/`。

### 项目自己的连接层

成熟工具不会自动理解本项目的轮播克隆、弹窗和餐车原生 CSS 动画，因此保留了一层很薄的项目连接代码：

- 自动为预设根节点里的子元素生成稳定编辑 ID。
- 同一个餐车元素的三份轮播克隆共用同一组参数。
- 底层仍能识别约 221 个 UI 元素；默认“餐车专注”只列出 10 个餐车逻辑图层，避免内部节点和其他页面 UI 干扰。
- 退出“餐车专注”后，顶部才显示主画面、签到、图鉴和设置弹窗切换。
- “餐车时序参数”把镜头、车身、车轮、卷帘、招牌和菜单的原生时长映射进 Theatre 属性面板。
- 布局状态、餐车原生时间和 Theatre 项目状态可以合并为一个 JSON。

## 日常使用

先启动本地静态服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

打开：

```text
http://127.0.0.1:4173/?layout=1
```

### 调整餐车

1. 编辑器默认进入“餐车专注”，停止进场动画，只显示一整台银色餐车和餐车相关工具。
2. 左侧固定为 10 个逻辑图层：镜头、整车、银色车身、出餐区、菜单、窗口、卷帘、招牌、前轮和后轮。
3. 在折叠分类中点选零件，也可以直接点击中间餐车；内部图片会自动归到对应逻辑图层，不再出现 221 个零碎节点。
4. 使用蓝色手柄或直接拖动零件。拖动只改变 X/Y，不会自动把对象提到最上层。
5. “当前零件与图层”会显示中文路径和实际显示层；只有点击“下一层 / 上一层 / 置底 / 置顶”才改变遮挡关系。
6. 点“恢复原层”会清除手动层级，回到 CSS 原始层级。
7. “精细移动”可选择 `0.1 / 1 / 5 / 10px` 步长，并用四向按钮、标准方向键或小键盘 `2 / 4 / 6 / 8` 微调；按住 `Shift` 为当前步长的 10 倍。
8. 右侧常规属性面板可以调整宽高、缩放、旋转、透视、层级、透明度、显示和锁定。

调整车轮时展开“车轮”，选择“前轮”或“后轮”。面板会显示两轮轮心是否同高及像素差，点“两轮轮心同高”即可精确校正。

2026-07-29 用户交回的调整文件已固化为项目基准：前轮 `X=-26.1 / Y=43.3 / 缩放=0.8`，后轮 `X=19.2 / Y=43.4 / 缩放=0.8`。新电脑、清空浏览器缓存或普通首页都会直接使用这组值；“复位所选”和“全部复位”也会回到这组已验收基准，不再回到旧的错位车轮。

顶部“预览餐车动画”会临时退出完整餐车视图，按当前时间轴播放；动画结束后自动返回完整餐车视图。

Theatre Studio 默认收起并移到画面外，避免和常规属性面板重叠。只有需要关键帧和时间轴时才点“高级动画面板”。

### 精确对齐、吸附与透视

选中元素后，左侧图层树旁会常驻“对齐与外观”面板：

- “左边 / 水平中 / 右边 / 上边 / 垂直中 / 下边”会把元素对齐到当前参考边界；餐车零件默认以完整餐车边界为基准，出餐区内的零件以出餐区边界为基准。
- “边距”用于保留与场景边缘的距离。例如填 `12` 后点“左边”，元素左边缘会落在场景左边缘内侧 12px。
- “网格”可以选择 1、4、8、12、16、24 或 32px；打开“显示网格”后会在当前对齐范围内绘制网格。
- 打开“自动吸附”后，手动拖到边缘、水平/垂直中心线或网格附近会自动贴合。
- 方向键每次微调 1px；`Shift + 方向键` 每次微调 10px。
- “不透明度”使用 0%～100% 滑杆；“层级”控制前后遮挡。
- “透视 px”配合“横向透视”和“纵向透视”可调整卡片式透视；完整属性面板还提供透视原点 X/Y。
- 网格默认关闭，避免看不清银色车身；需要时再勾选“显示网格”。

对齐会换算餐车镜头自身的缩放矩阵，因此即使全车编辑视图使用 90% 缩放，一键贴边和拖拽吸附仍会落到真实参考线，不会留下肉眼可见的误差。

### 制作关键帧动画

1. 点顶部“高级动画面板”，再选择需要动画的 UI。
2. 在 Theatre 属性右侧点击 `Sequence this prop`，把该属性加入时间轴。
3. 移动底部播放头，再修改属性数值；Theatre 会在当前位置写入关键帧。
4. 在底部时间轴调整关键帧位置和缓动曲线。
5. 顶部“播放时间轴”从头预览。

适合直接做：

- 餐车或招牌进入、退出。
- HUD、按钮、文字的弹入和淡入。
- 菜单灯箱、卷帘或出餐控件的位移、旋转、缩放、透明度动画。
- 页面切换后的回弹和强调动画。

### 调整餐车原生进场

1. 点击顶部“餐车时序参数”。
2. Theatre 右侧会显示镜头起点/终点、聚焦缩放、车身回弹、车轮滚动、卷帘、招牌和菜单周期。
3. 修改数值后点击“重播餐车”。
4. 镜头动画名称仍为 `burger-truck-camera-arrive`，不会破坏现有进场结束监听。

## 保存、导入和跨电脑交接

顶部“暂存到浏览器”会写入当前浏览器：

- `burger.home.layout.v2`：布局、样式、快速动画和餐车原生时间。
- `burger.home.theatre.v1`：Theatre 项目、关键帧和时间轴。

顶部“下载调整文件”会下载一个可以直接上传给 Codex 的组合文件，文件名类似 `汉堡小馆-UI调整-2026-07-28T17-30-00.json`：

```json
{
  "format": "burger-ui-adjustment",
  "version": 2,
  "project": "KIDCadillac/threejs_burger",
  "handoff": {
    "purpose": "把可视化 UI 与动画调整交给 Codex，并固化到项目代码"
  },
  "summary": {
    "editedElementCount": 1,
    "editedElementIds": ["burger.sign"],
    "includesTheatreTimeline": true
  },
  "layoutDocument": {},
  "theatreState": {}
}
```

调整完成后的推荐交接：

1. 点击“下载调整文件”。
2. 把下载的 JSON 直接上传到 Codex 对话。
3. Codex 读取 `layoutDocument` 和 `theatreState`，把确认后的参数固化到项目默认代码。

在另一台电脑恢复继续编辑：

1. 拉取 `main`。
2. 打开 `?layout=1`。
3. 点击“导入调整文件”，选择 JSON。
4. 页面会自动重载，布局和 Theatre 时间轴一起恢复。

注意：浏览器 `localStorage` 不会通过 Git 自动同步。拖动完成后必须下载调整文件；仅点击“暂存到浏览器”不能完成跨电脑交接。

## 代码结构

- `home-layout-editor-state.mjs`：v2 数据规范、迁移、校验、撤销历史。
- `home-layout-guides.mjs`：对齐设置、六向对齐和拖拽吸附的纯计算模块。
- `home-layout-editor.mjs`：深层元素注册、Moveable/Theatre 连接、导入导出和餐车参数映射。
- `home-layout-editor.css`：开发工作台、图层树和 Moveable 视觉。
- `home.css`：餐车动画 CSS 变量和原生关键帧。
- `vendor/moveable/`：Moveable 浏览器构建与许可证。
- `vendor/theatre/`：Theatre Studio/core 浏览器构建与许可证。
- `tests/home-layout-editor-*.test.mjs`：状态模型和接线回归。

## 已知边界

- 自动生成的子元素 ID 依赖同一根节点里的 DOM 顺序；大改 HTML 后要重新确认旧 JSON。
- 餐车专注模式导出的仍是完整 v2 调整文件；10 个图层是编辑视图过滤，不会丢失已存在的其他页面数据。
- Studio 是开发工具，不会在 GitHub Pages 普通首页出现。
- Theatre 关键帧保存到浏览器和导出 JSON，但不会自动改写源代码；需要 Codex 在确认后固化默认值。
- 已固化进代码的项目基准会自动加载；当前浏览器中明确保存过的本地调整仍优先于项目基准，点“全部复位”即可恢复仓库基准。
- 原生餐车动画与 Theatre 通用 UI 时间轴是两套可组合轨道：前者用“重播餐车”，后者用“播放时间轴”。
