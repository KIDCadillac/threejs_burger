# 汉堡小馆 UI 与动画编辑器

更新：2026-07-30

## 地址

- 普通首页：`https://kidcadillac.github.io/threejs_burger/`
- 编辑模式：`https://kidcadillac.github.io/threejs_burger/?layout=1`

编辑器只用于项目所有者调整 UI、档口构图和动画。普通玩家页面不会显示图层树、检查器或编辑手柄。

## 当前编辑目标

首页汉堡场景已经从“完整餐车”改为“悬吊出餐档口”。编辑器默认打开“档口专注”，只展示当前汉堡卡片和 8 个逻辑层：

1. 档口镜头
2. 完整悬吊档口
3. 银色档口边框
4. 出餐区域
5. 菜单灯箱
6. 后厨与人物
7. 卷帘
8. 汉堡档口招牌

车头、车身和前后轮不再属于可编辑结构。

## 选择与移动

- 在左侧图层树点击目标，或直接点击中间预览。
- 拖动只改变 X/Y，不会自动改变图层顺序。
- 方向键：每次移动 `1px`。
- `Shift + 方向键`：每次移动 `10px`。
- 数字小键盘：
  - `4` 左
  - `6` 右
  - `8` 上
  - `2` 下
- 中间的四个微调按钮可在键盘焦点被输入框占用时替代键盘。

输入框正在编辑文字或数字时，方向键只控制输入框，不移动画面元素；点击画布或图层后再使用快捷键。

## 对齐与吸附

“对齐到当前容器”提供：

- 左边
- 水平中
- 右边
- 上边
- 垂直中
- 下边

档口外层零件默认以完整悬吊档口为参考；菜单、窗口和卷帘以出餐区域为参考。开启“自动吸附”后会优先吸附容器边缘、中线和其他可见参考线，再按网格吸附。

建议流程：

1. 先选参考容器。
2. 用一键对齐确定大位置。
3. 开启 `1px` 或 `4px` 网格。
4. 用键盘做最后微调。

不要只靠鼠标猜像素位置。

## 图层顺序

选中零件后，左侧会显示当前所属层和顺序。可使用：

- 下一层
- 上一层
- 置底
- 置顶
- 恢复原层

拖动不会自动把元素放到最上层。只有点击这些按钮或修改“图层级别”才会改变遮挡关系。

## 样式与透视

右侧检查器分为布局、样式、动画和档口时间轴：

- X / Y
- 宽度 / 高度
- 缩放 / 旋转
- 透视距离
- X/Y 透视角度
- 透视原点
- 图层级别
- 不透明度
- 显示 / 锁定
- 亮度 / 饱和度 / 模糊
- 圆角 / 背景 /文字色

透视值为 `0` 时关闭透视。档口是正面扁平舞台，常规调整应保持透视为 `0`；只有做特意的翻牌或纸片旋转时才使用透视。

## 档口原生进场

“悬吊档口进场时间轴”控制：

- 起始 X / Y / 缩放
- 结束 X / Y / 缩放
- 总镜头时长
- 档口下落与停摆时长
- 卷帘延迟与时长
- 菜单翻牌周期与错峰

当前基线：

- 起始 Y：`-165`
- 总时长：`3150ms`
- 下落与停摆：`2200ms`
- 卷帘延迟：`2200ms`
- 卷帘时长：`620ms`

车轮和招牌独立动画参数已删除。整块档口必须作为一个组合运动。

“预览档口动画”会播放一次当前参数，结束后回到可编辑终态。

## 下载和交回调整文件

点击“下载调整文件”会生成：

`汉堡小馆-UI调整-日期时间.json`

文件包含：

- `layoutDocument`：布局、样式和档口时间参数
- `theatreState`：高级关键帧
- `summary`：已调整元素列表

将这个 JSON 直接上传给 Codex，即可把浏览器中的调整写回代码。只点击“暂存到浏览器”不会同步到 GitHub，也不会自动带到另一台电脑。

## v4 迁移规则

- 当前存储键：`burger.home.layout.v4`
- 当前工作台文件版本：v4
- 仍读取 v1/v2/v3
- 迁移时删除：
  - `burger.body`
  - `burger.wheel-front`
  - `burger.wheel-rear`
- 其他页面 UI 调整保留。

因此旧车轮 JSON 可以继续导入，但车轮数据不会出现在新档口里。

## Theatre 面板

点击“高级动画面板”才加载 Theatre Studio。它用于复杂 UI 关键帧，不是日常对齐工具。

- 对齐、位置、透明度：优先使用普通检查器。
- 连续关键帧：使用 Theatre。
- 档口吊降与卷帘：使用“悬吊档口进场时间轴”。

三套控制分开是为了避免一个数值同时被多个系统覆盖。

## 常见问题

### 键盘不移动

先确认：

1. 已选中一个图层。
2. 光标不在输入框中。
3. 元素没有锁定。
4. 浏览器没有把数字小键盘当作其他系统快捷键。

### 调整后换电脑看不到

“暂存到浏览器”只写当前浏览器。请下载 JSON，或让 Codex把结果写回仓库并推送 GitHub。

### 导入后车轮不见了

这是 v4 的预期行为。首页已取消车辆结构，旧车轮数据会被过滤。

### 绳索没有接到边框

确认页面资源版本为 `20260730-booth2`，然后强制刷新。旧版 `booth1` 的浏览器缓存可能仍显示较短提线。
