# 汉堡游戏项目契约

## 当前产品方向

- 先把汉堡制作体验做完整，再扩展寿司。
- 料理页是第一人称做菜台，不出现完整厨师身体、餐车、车头、轮子或卡片式店铺叙事。
- 汉堡按明确订单顺序组装；木偶感来自短暂出现的手和有重量的运动，不把汉堡本身做成木偶。
- 首页中央只展示一个持续旋转的料理主体。
- 左右滑动或左右方向键只切换汉堡与寿司。
- 上下滑动或上下方向键只切换玩法模式。

## 交互不可破坏项

- 左侧食材由左手拿取，右侧食材或调料由右手拿取；手型、拇指方向和进场侧必须一致。
- 料理手必须是食品手套与厨师袖的可读轮廓；不使用裸露木杆或细长木棍模拟前臂。不同物品应使用尺寸和抓法相符的关节姿势，不能只移动同一个冻结手势。
- 手应在拿起、移动、使用和放下期间与食材或工具保持接触，不能只在结束后闪现。
- 手和工具释放后快速、明确退场，不常驻遮挡餐盘。
- 调料瓶、食材与手不能悬空各自运动。
- 相邻主题或模式切换时不能叠到中心主体上。
- 动画要有重力、张力、惯性或接触等可解释原因，不能轻飘、无来源弹跳。

## 视觉不可破坏项

- 风格是暖色、扁平、手绘感、深棕描边的轻松小游戏。
- 避免高光过度、塑料质感、写实渲染和常见 AI 海报光效。
- 保持主体轮廓清晰、比例可读、操作目标无遮挡。
- 重要素材使用仓库现有合格资产或专门生成/绘制的透明素材，不用 emoji、随意 CSS 图形或占位文字代替。
