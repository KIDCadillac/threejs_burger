# 《女巫的毒药：零食乱斗篇》双人原型

一个可本地运行的双人回合制网页原型。两名玩家在同一盘公共零食中分别秘密部署一个陷阱，然后通过公开瞄准、表情误导和一次改选轮流拿取；吃到对手的陷阱立即落败，并播放夸张表情和该件零食的下料回放。

## 已实现

- 真人快速匹配、取消匹配。
- 六位好友房间码、邀请链接自动入房与手动入房。
- 公共盘混合薯条、鸡块、甜甜圈、曲奇、洋葱圈和糯米团，双方看到并拿取的是同一批位置。
- 每人秘密选择 1 件公共零食和 2 份调味料，服务端不会提前泄露对手位置或配方。
- 部署期间对手能看到“鬼鬼祟祟、搅拌、封口”等角色动作，但动作数据不含目标零食。
- 每回合先公开瞄准；对手可用固定搞怪动作误导，拿取者最多改选一次后确认。
- 服务端权威的轮流选择、胜负、平局、20 秒自动选择和 30 秒断线宽限。
- 辣椒、芥末、酸汁、黏酱四类反应，支持同种或混合配方连播；命中后自动播放单件下料回放并可重复观看。
- 双方确认重赛、首手轮换，以及任一方返回首页时双方同步离房。
- 390px 手机宽度适配、键盘焦点和减少动态效果支持。

所有“辣、酸、黏”等效果只发生在虚拟角色上，不包含真实进食挑战或暴力惩罚。

## 建议验收顺序

1. 用两个独立标签页打开首页，两边依次点“快速匹配”，确认进入同一个房间。
2. 两边各从同一公共盘选一件零食、加入两份调味料并下料；确认对方能看到角色动作，但看不到目标位置和配方。
3. 当前玩家瞄准一件零食；对手发送“指错方向”等动作；当前玩家改选一次并确认吃下。
4. 选中对手陷阱，检查大表情、赢家偷笑、编辑式字幕、单件下料回放和“再看一次下料回放”。
5. 两边依次点“再来一局”，确认只有双方同意后才重开，且下一局首手交换。
6. 返回首页后点“邀请好友”，复制链接到另一个标签页，确认自动入房；刷新邀请页不应重复入房或报“房间已满”。
7. 在胜负页任意一边点“返回首页”，确认双方同时回到首页。

## 原型边界

- 房间和对局存于单个 Python 进程内，服务重启后清空。
- 当前玩家身份使用标签页级 `sessionStorage`，还没有接入抖音登录。
- `platform.js` 已预留邀请适配边界，本地版使用链接/房间码；抖音好友面板、私信卡片、正式审核、云端部署和商业化尚未接入。
- 这是原创机制验证原型，不使用参考游戏的名称、美术、角色、数值或完整规则组合。
