# 《女巫的毒药：零食乱斗篇》对战原型

一个可本地运行的回合制网页原型，支持立即挑战电脑女巫、真人快速匹配和好友邀请。双方在同一盘公共零食中分别秘密部署一个陷阱，然后通过公开瞄准、表情误导和一次改选轮流拿取；吃到对手的陷阱立即落败，并播放夸张表情和该件零食的下料回放。

## 已实现

- 真人快速匹配、取消匹配。
- 首页“单人练习”和匹配页“没人？和电脑玩”均可立即创建电脑对局，不依赖第二个浏览器或外部机器人脚本。
- 电脑女巫会分步表演搅拌、封口、瞄准、搞怪动作、可能改选和确认吃下；电脑策略只接收公开选项，不读取玩家的秘密配方。
- 六位好友房间码、邀请链接自动入房与手动入房。
- 公共盘混合薯条、汉堡、甜甜圈、曲奇、三明治和果冻，使用偏真实的卡通食物素材；双方看到并拿取的是同一批位置。
- 每人秘密选择 1 件公共零食和 1～4 份调味料，支持重复、混搭与按加入顺序回放；服务端不会提前泄露对手位置或配方。
- 秘密部署采用卡通写实料理操作台：必须依次选择食物、切开或打开、把调料瓶拖进食物、合回去伪装；拖错位置会取消，食物内部会显示逐层酱料。
- 部署完成后切换为双人同桌场景，角色表情和公共餐盘同时可见；食物仍由服务端公共状态驱动。
- 首次单人练习提供“边玩边学”提示，分别解释公共零食、秘密打开、下料和同桌确认吃下。
- 部署期间对手能看到“鬼鬼祟祟、搅拌、封口”等角色动作，但动作数据不含目标零食。
- 每回合先公开瞄准；对手可用固定搞怪动作误导，拿取者最多改选一次后确认。
- 服务端权威的轮流选择、胜负、平局、20 秒自动选择和 30 秒断线宽限。
- 辣椒、芥末、酸汁、黏酱四类反应，支持同种或混合配方连播；命中后自动播放单件下料回放并可重复观看。
- 双方确认重赛、首手轮换，以及任一方返回首页时双方同步离房。
- 390px 手机宽度适配、键盘焦点和减少动态效果支持。

所有“辣、酸、黏”等效果只发生在虚拟角色上，不包含真实进食挑战或暴力惩罚。

## 建议验收顺序

1. 在手机首页点“单人练习”，确认不经过匹配等待便进入部署阶段。
2. 选择一件零食，点击“切开/打开”，确认此前调料瓶不可用；打开后按住调料瓶拖进食物，加入 1～4 份，再点“合上食物，完成伪装”。
3. 确认画面切换到双人同桌场景；在自己的回合公开瞄准、发送动作、改选并确认，在电脑回合观察它依次瞄准、做动作、可能改选并吃下。
4. 任一方吃中陷阱时，检查大表情、赢家偷笑、编辑式字幕、单件下料回放和“再看一次下料回放”。
5. 单人结算页点一次“再来一局”，确认立即重开并交换首手。
6. 返回首页点“快速匹配”，在等待页点“没人？和电脑玩”，确认取消真人排队并立即进入电脑局。
7. 用两个独立标签页依次点“快速匹配”，确认真人双方进入同一个房间；真人重赛仍需双方分别同意。
8. 返回首页点“邀请好友”，复制链接到另一个标签页，确认自动入房；刷新邀请页不应重复入房或报“房间已满”。
9. 在胜负页任意一边点“返回首页”，确认双方同时回到首页。

## 原型边界

- 房间和对局存于单个 Python 进程内，服务重启后清空。
- 当前玩家身份使用标签页级 `sessionStorage` 保存随机玩家 ID 和独立秘密重连令牌；服务端会拒绝用错误令牌冒充同一玩家，但还没有接入抖音正式登录。
- 单人电脑目前为公平随机策略，尚未加入难度等级、人格、成长或奖励系统。
- `platform.js` 已预留邀请适配边界，本地版使用链接/房间码；抖音好友面板、私信卡片、正式审核、云端部署和商业化尚未接入。
- 这是原创机制验证原型，不使用参考游戏的名称、美术、角色、数值或完整规则组合。
