# 《女巫的毒药：薯条篇》双人原型

一个可本地运行的双人回合制网页原型。两名玩家分别秘密选择一根薯条并加入两份虚拟调味料，然后轮流从公共餐盘取薯条；吃到对手的整蛊薯条立即落败，并播放对应的卡通表情演出。

## 已实现

- 真人快速匹配、取消匹配。
- 六位好友房间码、邀请链接自动入房与手动入房。
- 每人秘密选择 1 根薯条和 2 份调味料，服务端不会提前泄露对手配方。
- 服务端权威的轮流选择、胜负、平局、20 秒自动选择和 30 秒断线宽限。
- 辣椒、芥末、酸汁、黏酱四类反应，支持同种或混合配方连播。
- 双方确认重赛、首手轮换，以及任一方返回首页时双方同步离房。
- 390px 手机宽度适配、键盘焦点和减少动态效果支持。

所有“辣、酸、黏”等效果只发生在虚拟角色上，不包含真实进食挑战或暴力惩罚。

## 建议验收顺序

1. 用两个独立标签页打开首页，两边依次点“快速匹配”，确认进入同一个房间。
2. 两边各选一根薯条、加入两份调味料并封装；确认只能看到自己的秘密位置和配方。
3. 轮流选择安全薯条，再选中对手的整蛊薯条，检查胜负、配方揭晓和两段表情动画。
4. 两边依次点“再来一局”，确认只有双方同意后才重开，且下一局首手交换。
5. 返回首页后点“邀请好友”，复制链接到另一个标签页，确认自动入房；刷新邀请页不应重复入房或报“房间已满”。
6. 在胜负页任意一边点“返回首页”，确认双方同时回到首页。

## 原型边界

- 房间和对局存于单个 Python 进程内，服务重启后清空。
- 当前玩家身份使用标签页级 `sessionStorage`，还没有接入抖音登录。
- `platform.js` 已预留邀请适配边界，本地版使用链接/房间码；抖音好友面板、私信卡片、正式审核、云端部署和商业化尚未接入。
- 这是原创机制验证原型，不使用参考游戏的名称、美术、角色、数值或完整规则组合。
