# Autonomous execution plan

For substantial work, follow this loop:

1. Audit the repository, existing behavior, tests, saves, and deployment.
2. Write or update a concrete implementation plan.
3. Add failing tests for the next observable behavior.
4. Implement the smallest coherent feature slice.
5. Launch the project and inspect served state and console.
6. Exercise the feature on desktop, tablet, and mobile dimensions.
7. Play complete rounds when gameplay is affected.
8. Record the worst visual, interaction, continuity, and performance issues.
9. Fix those issues and repeat verification.
10. Report only verified results, remaining risks, and the public test link.

Continue automatically between steps. Ask the user only when an undiscoverable decision would materially change the product.
